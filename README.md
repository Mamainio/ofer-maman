# עופר ממן — גלריה

אתר הגלריה של עופר ממן: ציורי שמן ריאליסטיים.

- `index.html` — כל האתר (HTML, CSS ו-JS בקובץ אחד)
- `works/` — הציורים בגודל מלא, `works/thumbs/` — תמונות מוקטנות לרשת
- להוספת יצירה: לשים את התמונה ב-`works/` ו-`works/thumbs/`, להוסיף שורה לרשימה `COLLECTION` ב-`index.html`, ולהעלות את `COLLECTION_VERSION` באחד.
